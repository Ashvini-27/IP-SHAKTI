# IP-SAKTI Sahayak

### AI-Assisted IP Guidance for Ayurveda

IP-SAKTI Sahayak is an AI-powered assistant that helps Ayurveda researchers, innovators and startups understand Intellectual Property protection for formulations, brands, written works and traditional knowledge.

## Key Features

- Ayurveda-focused IP guidance
- Patent, Trademark, Copyright and GI guidance
- RAG-based information retrieval
- Source-backed responses
- Confidence-based answers
- Multilingual support

## Tech Stack

- React + Vite
- Python + FastAPI
- Gemini API
- RAG
- Vercel + Render
